## 一、处理哪些信息及其用途

本地游戏记录：关卡进度、探索经验与等级、研究等级、装备、芯片、外观、背包、虚拟货币、奖励领取与结算标记，用于恢复进度、成长管理及避免重复结算。

本地偏好：音量、战斗倍速、体力恢复时间和隐私选择。隐私选择记录包括政策版本、选择结果和本机时间，仅用于记住您的选择，不作为广告授权的替代凭据。

本地运行信息：屏幕尺寸、安全区域、操作系统及图形和音频运行环境，用于适配画面与声音。本地日志可能记录错误及运行环境；游戏不自动将日志上传给我们。

主动反馈：您自行发送的联系邮箱、问题描述以及自愿附带的截图或日志，仅用于回复、排查和处理相关请求。请勿发送密码、身份证照片或无关敏感信息；发送前请遮挡无关个人资料。

游戏不收集手机号、姓名、身份证号、银行卡信息、通讯录、相册、麦克风或相机内容。广告SDK可能处理必要的设备、网络及广告交互数据，详见第六节。当前桥接关闭位置、电话状态、Wi-Fi状态、外部存储、应用列表与Android ID采集，不主动提供IMEI或OAID。

广告奖励记录：本地保存每日体力奖励次数、日期及随机领取凭据，用于防止重复奖励；普通三选一广告资格仅在本局内有效。体力每日最多三次，每次增加30点且不超过上限，日期按UTC+8划分。未提供开发者服务器验奖或跨设备同步。

## 二、设备权限与主动操作

接入激励广告的Android版本声明INTERNET（请求广告、下载视频与上报广告事件）及ACCESS_NETWORK_STATE（判断网络可用性）；不申请定位、电话、相机、录音、通讯录、全部应用列表或请求安装应用权限。旧版离线包未声明联网权限。读写应用自己的存档目录不等于读取您的全部文件。

您在游戏内选择复制联系邮箱时，仅向系统剪贴板写入公开联系邮箱；游戏不读取剪贴板内容。若您主动点击已提供的在线政策链接，系统浏览器会访问外部网页，该访问由浏览器与网站服务商处理。不会在游戏启动时自动请求该网页。

TapPlay等外部运行环境自身的权限或信息处理，不等于游戏本体声明了相同权限。新增SDK或权限前，我们会按实际情况更新政策并履行告知、同意等要求。

## 三、保存位置、期限与删除

游戏记录保存在设备或TapPlay等运行环境提供的应用目录中，保存至您清除相关数据、删除文件或系统进行清理。程序会更新本地备份和日志；系统或平台的备份恢复规则由对应服务提供方说明。

我们没有用于接收游戏进度的自建云存档服务器，不提供从开发者服务器恢复进度的服务。TapPlay环境的存档与独立安装版不自动互通。

您主动提交的反馈资料仅在处理事项、履行请求及必要安全核查所需的最短期限内保留，无继续留存必要时删除，法律法规另有要求的除外。所选邮箱服务商可能涉及跨境邮件传输，其基础设施和处理适用其政策；我们不主动将本地游戏存档传输到该服务。

## 四、Cookies与网络访问

游戏的本地玩法与存档不使用网页Cookies或广告追踪像素，本地存档及隐私选择文件不用于广告画像。已启用广告版本中的广告网页可能使用缓存、Cookies等技术，具体依广告服务商的政策及实际页面说明；我们不将其描述为完全不涉及网络追踪。

本政策的在线网页版不添加统计脚本、广告脚本、第三方字体或追踪工具。若部署在GitHub Pages，托管方在您访问网站时可能处理IP地址和技术请求日志，具体由GitHub隐私声明说明；不能据此认为网页托管也完全不处理访问数据。

## 五、共享、委托、转让与公开披露

Android广告功能由TapADN SDK提供，会与其服务端通信，详情见第六节。我们不出售个人信息，不将主动反馈资料用于广告画像，不通过广告SDK上传本地游戏存档。

处理您主动发来的反馈时，可能涉及您自行选择的邮件服务。若未来确需委托或向其他服务商提供个人信息，将依法履行必要的告知、同意、约定与安全保护义务。

涉及合并、转让等情形而需要转移个人信息时，会依法告知接收方并要求其继续履行保护义务；变更处理目的或方式时依法重新取得同意。公开披露或向有权机关提供信息时，仅在适用法律允许或要求的范围内进行。

## 七、信息安全

程序通过应用目录、临时文件与备份降低意外写入造成的进度丢失。存档不是加密保险箱，我们不把尚未实施的加密、服务器隔离或员工控制机制描述为已有保护措施。请妥善保护设备与自行导出的存档副本。

我们将限制主动反馈资料的使用范围。如发生涉及我们处理的信息安全事件，将依法采取补救措施，通知受影响用户并履行相应报告义务。本政策不排除或限制您依法享有的权利。

## 八、您的选择及权利

在“设置 → 隐私与服务”可查看政策、用户协议、第三方服务及联系方式；在“隐私设置”可重新选择或撤回同意。撤回后游戏停止新的广告请求并释放缓存；SDK没有公开全局反初始化接口，已启用时请关闭并重启游戏以保持SDK不初始化。撤回不删除进度，不影响此前合法处理。新增目的或SDK需重新告知，不沿用旧离线版同意启用广告。

暂不同意不阻止本地功能，但不能使用广告奖励。此选择不绕过发行平台的实名、防沉迷或年龄限制。

您可以通过游戏页面查看关卡、装备与成长等记录。Android本地数据可在系统设置中选择本应用并清除数据；Windows删除程序不一定删除存档，可谨慎移除本应用存档目录相关文件。删除会丢失进度；如不确定文件位置，请先联系开发者。

当前没有联网游戏账号，因此没有游戏账号注销流程。平台账号注销请使用对应平台的入口。对您主动提供给我们的反馈资料，可通过邮箱提出查阅、复制、更正、删除、撤回同意等请求。

我们一般在15个工作日内答复，仅进行与请求相称的必要核验，不把提供无关身份证信息作为常规条件；不能满足请求时会说明原因。您也可向有权部门投诉或依法寻求其他救济。
